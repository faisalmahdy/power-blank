# POWER BLANK

Browser tactical FPS — CT vs TR demolition, TDM, and elimination. Lobby, shop, loadout, bots, and a Point Blank–style orange military look. Original name and original assets.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

```bash
npm run typecheck
npm run build
```

## Stack

- Vite + TanStack Start + React
- Three.js FPS (fixed 1/60 step)
- Zustand match/lobby state
- Web Audio gun / radio / footsteps

## Play

1. **QUICK MATCH** or **CHANNELS** → room → **START MATCH**
2. Freeze buy, then plant / defuse on Depot
3. Touch stick on phone; mouse + WASD on desktop
4. **ARMORY** for GP unlocks (saved locally)

Not affiliated with Zepetto or Point Blank.
